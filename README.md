# 🤖 Waste Sorting Robot 3-DOF

Automatic Waste Sorting Robot using **YOLOv11-Seg**, **ESP32**, **PLC Omron**, and **3-DOF Robotic Arm**.

---

## 📸 Robot

![Robot](Rendering/Robotic%20Arm.png)

---

## 🚀 Features
- YOLOv11 Instance Segmentation
- 3-DOF Robot Arm
- PLC Conveyor Control
- ESP32 Motion Control

---

## 🛠 Hardware

- ESP32 DevKit V4
- Omron CP1L PLC
- NEMA17 Stepper Motor
- A4988 Driver
- Webcam
- Vacuum Pump

---

## 💻 Software

- Python
- OpenCV
- Ultralytics YOLOv11
- Arduino IDE
